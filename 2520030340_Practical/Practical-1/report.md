# OSSP Practical 1

## Aim
To demonstrate Linux process creation using fork(), exec(), and wait(), and to study Linux hardware resources using Linux commands.

## Commands Used
- uname -a
- lscpu
- lsblk
- ps
- top

## Observations

### uname -a
Displays Linux kernel and system information.

### lscpu
Displays CPU architecture and processor details.

### lsblk
Shows storage devices and partitions.

### ps
Displays currently running processes.

### top
Shows live CPU and memory usage.

## Conclusion
The Linux operating system manages CPU, memory, storage, and I/O devices efficiently through the kernel and provides an abstraction layer between hardware and applications.
